# ScuttlePod

ScuttlePod is a secure, local-first AppLocker and privacy utility designed to protect your device from unauthorized access and data extraction.

## Key Features:
- Advanced local AppLocker with Master and Guest PIN separations.
- Silent Intruder Photo captures upon unauthorized unlock attempts.
- Secure zero-fill folder shredding (Panic Wipe).
- Remote emergency backups and triggers (SMS keywords and Dead Man's Switch).

All data remains strictly offline, encrypted, and on-device. No accounts, cloud logins, or background tracking are used.
